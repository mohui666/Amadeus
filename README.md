# Amadeus

面向手机竖屏的《命运石之门 0》Amadeus 非官方复刻，提供本地网页和 Android APK。使用现有红莉栖立绘、网格背景、Logo 动画和原有语音片段；自由对话连接真实模型。Android 默认显示 CONNECT／CANCEL 与人物通话画面，点击人物展开操作栏；高屏幕保留画幅比例。网页右上角展开按钮切换沉浸画面。

Android 安装包：`artifacts/android/Amadeus.apk`。构建、连接电脑和安卓 16 模拟器实测见 [手机版说明](docs/ANDROID.md)。需要自行部署电脑服务，配置见 [远程连接](docs/REMOTE.md)。

已按实际游戏、动画画面对照修正手机构图，来源见 [素材说明](ASSETS.md)。当前采用游戏立绘，尚未达到动画逐帧复刻。

设置分为对话、声音、角色、记忆四页，声音页只显示自动朗读、语速、输入语言，服务和接口统一在高级设置中展开。设置自动保存，只需点「完成」关闭。朗读方式分为系统语音和 API；API 格式只有 OpenAI 兼容、GPT-SoVITS、ElevenLabs，千问属于 OpenAI 兼容格式。记忆页仅保留自动记忆状态、已保存内容和删除操作。成功回复后使用当前聊天模型自动分批提取个人资料、偏好、目标、事件、关系和剧情，区分现实与虚构，保留原话证据；更正生成新事实并保留历史版本。本地 BM25 与实体关联先选候选；超过 8 条时自动按语义筛选，增加一次模型请求和等待时间。设计、参考项目和容量边界见 [智能记忆说明](docs/MEMORY.md)。

手机 APP 将记忆和对话保存在应用私有目录，独立于电脑服务地址；升级时保留原有记录。网页版保存在当前浏览器，不跨设备同步。清空对话不会清空记忆，清空记忆也不会从对话记录重新导入。图片和设置密钥不会写入记忆，需要整理和检索的文本会随请求发送给所选聊天模型。

为减少等待，每轮仅发送最近最多 12 条消息（通常不超过 16000 字符，最新单条长消息保留完整）及最多 24 条相关记忆（含依据的 JSON 预算约 14000 字符），原始对话记录仍保留。语音 API 等待本条回复生成完成，再将朗读文本整段合成，减少逐句生成导致的音高、音色跳变；首段声音需要等完整合成后才开始播放，文字仍流式显示。双语模式只合成 `[speech:ja]` 后的日语。系统语音仍在完整回复后朗读。新消息、停止朗读和挂断可取消待播放语音。整段 API 语音生成后立即保存：APP 使用私有文件，网页使用 IndexedDB。重播优先使用保存的原音频，重开 APP 后或离线时也可播放完整缓存；旧分句缓存继续原样重播，不会自动改写其音色；旧的未完成缓存复用已保存片段，剩余文本整段合成。系统朗读不提供音频文件，仍由设备实时朗读。卸载 APP 或清除应用数据会移除本地记录和语音。

API 语音在播放前按有效语音段的 RMS 电平对每段音频校正音量，跳过静音并保留句内轻重变化；目标为 -20 dBFS，最多放大 12 dB，并为采样峰值保留 1 dB 余量。这是播放端处理，新生成、完整缓存和部分缓存重播均适用，保存的原音频不变；原作片段和设备系统朗读不做此校正。

设计参考：[SillyTavern 的按需记忆](https://docs.sillytavern.app/usage/core-concepts/worldinfo/)、[Memobase 的用户画像与后台整理](https://github.com/memodb-io/memobase)、[Pipecat 的语音播放管线](https://docs.pipecat.ai/pipecat/learn/text-to-speech)。本项目采用本地实现，未引入这些项目的服务依赖。

## 启动

需要 Node.js 22.13+。首次使用先运行下面的网页后端命令；默认使用 Codex，也可在设置切换自己的 API。语音模型、Python 环境、私有配置与 APK 不随源码分发。

已自行准备完整 Windows 语音环境、网关和隧道时，可统一启停：

```powershell
npm run start:windows
npm run status:windows
npm run stop:windows
```

启动后模型在后台加载，日志见 `.local/windows/logs/`。入口未注册开机启动；服务运行时不要重复启动同端口进程。所需配置见 [远程连接](docs/REMOTE.md)。

只运行网页后端时：

```bash
npm ci
npm run build
npm start
```

打开 [http://localhost:3010](http://localhost:3010)。开发时使用 `npm run dev`，打开 [http://localhost:5179](http://localhost:5179)，前后端同时启动。

在 Linux / WSL 完成 [本机 GPT-SoVITS 安装](docs/VOICE.md) 后，可用下面的入口同时启动网页与语音服务；不要与已经运行的 `npm start` 或语音进程重复启动。按 Ctrl+C 关闭二者。

```bash
npm run start:local
```

Linux 的千问入口为 `npm run start:qwen`，Windows 使用上面的 `npm run start:windows`；两者默认加载已安装的 [starrydark/Kurisu_Qwen3_TTS](https://huggingface.co/starrydark/Kurisu_Qwen3_TTS) 1.7B 红莉栖模型。之前用 144 条原声训练的 0.6B LoRA 模型仍保留；安装位置、试听与历史训练结果见 [千问说明](docs/QWEN-TTS.md)，素材见 [录音数据](docs/KURISU-DATA.md)。切换启动入口前先关闭正在运行的入口，在“声音 → 高级声音设置”选择对应服务。

## OpenAI 账号登录

默认使用运行后端这台电脑的 **Codex 官方账号连接**。本次验证的 Codex CLI 版本为 `0.150.1`；需要 `codex` 位于 PATH，也可通过 `CODEX_BIN` 指定程序路径。账号登录与聊天使用官方 [Codex App Server](https://learn.chatgpt.com/docs/app-server) 协议。

1. 打开右上角「设置」。已有 ChatGPT 登录时会显示「已连接」。
2. 没有登录时，点击「使用 OpenAI 登录」，再打开返回的官方登录页。该浏览器流程在运行后端的电脑完成。
3. 手机可选「在手机上用设备码登录」，在官方页面完成验证；账号可能需要先启用设备码登录。
4. 设置自动保存，点击「完成」后输入文字即可对话。首次打开模型和推理强度留空，需要指定时手动填写；不自动获取模型列表，留空时由 Codex 使用默认配置。

Amadeus 不读取或复制 `auth.json`，不收集密码，不自动发起登录或退出已有账号。官方 Codex 负责凭证保存和刷新。这里是本机 Codex 对话接入；ChatGPT 登录不会变成普通 API Key，也不会自动提供语音 API 额度。每次对话使用独立临时会话与空目录，并禁用环境访问、工具、插件、MCP 和本地记忆读取。

模型名称由用户填写；不会自动恢复模型列表或预填自定义服务模型。模型比较的真实输出与选择依据见 [模型比较](docs/MODELS.md)。此账号登录方式使用 Codex 订阅额度；普通 API 的 token 单价不能直接当作这里每次聊天的费用。

## 角色与语言

网页和 APK 构建时内置完整的 [红莉栖提示词](prompts/kurisu.md)，每次请求携带人物提示词及手机本地检索的相关记忆，以记忆采集时点的原有经历与人格为基础，包含求知欲、自尊、关系变化、具体关怀和自然的数字身份认知；不预设你是冈部或恋人。2026-09-05 已对取得的全部 10,469 条日文记录及英文对话上下文作分批研究，见 [全量归纳](docs/KURISU-DIALOGUE-STUDY.md) 和 [角色说明](docs/PERSONA.md)。修改基础提示词后重新构建网页／安装新版 APK；设置里的「角色」可直接补充昵称和语气偏好。

首次打开默认「日语声音 · 中文字幕」，也支持中文或纯日文。双语模式先流式显示中文，再生成语义一致的日文供朗读；表情和语音标签不会显示在字幕中。日文段缺失时保留文字并显示错误，不自动读出错误语种。语音输入语言单独设置，可以用中文讲话、听日文回复。

## 文本与图像 API

设置中的「API 接入」仅提供 OpenAI 兼容、Responses、Anthropic 三种协议。地址、模型名称和密钥由用户手动填写，不自动获取模型或预填模型。地址填 API 前缀，例如 `https://api.openai.com/v1`，不包含 `/chat/completions`、`/responses` 或 `/messages`。账号登录模式的模型也默认留空，需要指定时再填写；已保存的用户配置保留。

图片按钮支持 JPG、PNG、WebP、GIF，单张 8 MB 以内。图片作为对话输入发送给所选服务，因此必须选择支持图像的模型。对话会以流式方式显示，可中止生成。

地址、模型、声音、偏好和 API Key 自动保存在此设备；切换协议后保留各自的配置，刷新或重启无需重填。Android 使用应用私有文件，网页版使用当前来源的 localStorage；没有加密或跨设备同步。密钥随请求发送到本地后端，再转给选定服务。图片只在本次页面会话保留，对话导出与记忆不包含设置密钥。

## 声音

| 方式 | 已实现行为 | 需要准备 |
| --- | --- | --- |
| 原作语音片段 | 播放已有问候、自我介绍和经典短句，口型跟随实际音频幅度 | 无 |
| 系统朗读 | 用设备声音朗读新回复，配合节奏口型 | 浏览器支持 SpeechSynthesis；不是红莉栖原声 |
| 电脑本地识别（默认） | 手机录音通过密码网关送到电脑上的 Whisper base，CPU INT8 识别，无需额外 API Key | Windows 由 `start:windows` 启动；Linux 使用 `start:qwen` / `start:local` |
| 浏览器语音识别 | 麦克风输入，识别后发送消息 | 浏览器支持 SpeechRecognition 和麦克风权限 |
| OpenAI 兼容 STT | 录音上传 `/audio/transcriptions`，识别后发送 | 地址、识别模型、API Key |
| OpenAI 兼容 TTS | `/audio/speech` 生成语音 | 地址、模型、声音 ID、API Key |
| ElevenLabs | 指定 voice ID 合成回复 | 地址、模型、voice ID、API Key |
| GPT-SoVITS | `/tts` 生成角色语音 | 已运行的本地服务、已加载模型、服务端参考音频路径与原文 |
| Qwen3-TTS | 本机 `/v1/audio/speech` 合成训练后的红莉栖声音 | 已安装的 starrydark 1.7B 模型与运行中的千问服务 |

默认使用电脑本地识别，麦克风按钮开始录音，再次点击结束并发送。旧版默认的系统识别和未配置密钥的 OpenAI whisper-1 设置会改用本地识别，已自定义的 API 地址、模型和新版主动保存的选择保留。OpenAI 账号聊天登录不能代替语音 API Key；主动选择 OpenAI 识别时需要另外填写密钥。挂断会取消生成、播放、录音和未完成的识别。浏览器识别及系统声音由设备提供，支持范围与实际音色取决于浏览器和系统。

电脑 localhost 可申请麦克风权限；手机浏览器远程访问录音需要 HTTPS。Android APK 接入安卓系统语音识别和权限申请，API 录音使用 WebView 麦克风。USB 转发后的 localhost 支持 API 录音；局域网 HTTP 连接请使用安卓系统识别，或为 API 录音配置 HTTPS。后端仍仅监听 `127.0.0.1`；公网请求通过带用户名、密码验证的网关和服务器中转访问，见 [远程连接](docs/REMOTE.md)。后端提供 `HOST` 与 `PORT` 环境变量；若指定其他 HOST，应使用同一个明确主机地址访问，不能把 `0.0.0.0` 当作手机访问地址。

## 素材与还原边界

素材：19 种表情 × 3 个口型、39 帧 Logo 动画、背景和按钮、8 段已有录音。来源与逐文件路径见 [ASSETS.md](ASSETS.md) 和 [素材清单](public/assets/manifest.json)，主要来自 [Yink/Amadeus](https://github.com/Yink/Amadeus)。

这是可运行的复刻首版，尚不代表与动画逐帧完全一致。角色使用离散立绘帧，支持句中表情控制、自然眨眼、倾听点头与轻微呼吸，未使用 Live2D 或三维模型；控制协议见 [表情说明](docs/EXPRESSIONS.md)。AI 对话由人格提示与所选模型生成；新句子由运行中的语音模型合成，现有录音用于固定片段和音色参考。声音页仅展示自动朗读、语速与输入语言；服务和接口配置统一放入“高级声音设置”。

## 验证

```bash
npm test
npm run test:ui
```

`npm test` 使用本地 HTTP mock 与 Codex 协议 mock 验证文本/图像、三类 TTS、STT、登录、取消和资源服务。`test:ui` 需要先运行本地服务及 Playwright Chromium，使用测试夹具验证手机/桌面交互，不调用真实付费服务。

测试夹具不代表真实模型、语音服务或物理手机验证。其余文档中的带日期测试记录属于历史结果；本机原始截图、音频与日志未上传。
