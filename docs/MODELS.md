# Amadeus 聊天模型实测

核实日期：2026-09-05。使用本机已有 ChatGPT 登录，通过官方 Codex app-server 调用真实模型。中文三场景每个模型各一次，共九次；追加同一双语场景每个模型各一次，共三次。没有重跑挑选更好看的回答。

## 选择建议

优先用 **GPT-5.6 Sol + low** 做红莉栖日常角色对话，这是此前短测的建议；当前应用不再预填模型或强度，需要时手动填写。中文短测中，它的吐槽简洁，安慰时接住前文的“一周准备”，也遵守不列建议的要求。**Luna + low** 适合更看重额度、聊天量大的用法；**Terra + low** 是质量与资源消耗的折中，在本次日语称呼细节上还略好于 Sol。三者可以共用当前角色提示词，并保留手动切换。

这是对当前提示词和少量场景的体验判断，不能证明所有长对话里哪个最好。low 已足以完成这些短聊，不需要默认启用 high、max 或 ultra。OpenAI 官方建议使用能达到要求的最低推理强度；Sol 更强调判断和细节，Terra 面向日常工作，Luna 面向清晰、重复和高频任务。这里的角色选择是在官方定位基础上结合实际输出作出的推断。[官方模型与推理强度说明](https://learn.chatgpt.com/docs/models)

## 日语语音、中文字幕比较

同一条构造输入：“助手，你认真讲科学的时候还挺帅的。别急着反驳，我是在认真夸你。”每模型一次，均为 low，直接使用应用 `systemPrompt({config:{replyMode:'ja-zh'}})`。本组未合成音频，比较的是双语台词和格式。

| 模型 | 中文字幕首字 | 日语台词首字 | 全部生成完成 | 双语协议 |
|---|---:|---:|---:|---|
| Luna · low | 9.00 秒 | 10.06 秒 | 11.56 秒 | 通过 |
| Terra · low | 8.84 秒 | 9.47 秒 | 10.62 秒 | 通过 |
| Sol · low | 8.73 秒 | 9.38 秒 | 10.82 秒 | 通过 |

三者均输出一个合法表情标签、中文正文、单独的 `[speech:ja]` 和日文正文。逐句人工检查，双语主要意思一致，没有在日文另添事实、动作或问题。三者均用 blush 表达被夸后的害羞。

- **Terra**：日文“そんなふうに真剣に言ってくれて、ありがとう”自然地接受夸奖，再轻轻抗议“助手”的叫法。它保留日文原作昵称「助手」，此场景角色细节最好。
- **Sol**：短而自然地道谢，语义一致，中文也流畅；但把中文“助手”译成「アシスタント」，普通词义对，原作昵称的味道弱了一点。不能把这一例说成完全复刻。
- **Luna**：中日文意思对齐；回复更长，并把赞美转为“是论证严谨，不是我讲得快吧”的反问。更像在表演傲娇科学家，少一点顺畅随聊的感觉。

若更在意原作日语昵称，可以选 Terra low；若综合中文上下文承接、简洁度和自然交流，目前仍选 Sol low。这里只有一个双语场景，不能据此证明某模型的日语能力全面更好；也没有母语者盲评或音色盲听。日语台词生成时间与 GPT-SoVITS 推理、音频开始播放时间必须分开判断。

另通过运行中的 `3010 /api/chat` 对 Sol low 检查了现实科学纠错、暂停扮演后的真实身份和未上传图片时的感知边界；这两例未作跨模型比较，不计入上面的速度统计。

比较后，应用双语要求补充了专名称呼：助手 →「助手」，克里斯蒂娜 →「クリスティーナ」。对 Sol low 单独复验同一赞美场景，中文与日文含义一致，日文正确保留「助手」。这是提示词修改后的定向验证，未替换上表或下方的原始比较输出。

## 复现

在项目目录运行，会使用已有 ChatGPT 登录并消耗相应额度：

```bash
# 中文三个场景 × 三个模型，共九次请求
node scripts/compare-models.mjs --output /tmp/amadeus-model-comparison.json
# 应用的中文字幕、日语语音模式，一个场景 × 三个模型，共三次请求
node scripts/compare-models.mjs --suite ja-zh --output /tmp/amadeus-model-comparison-ja-zh.json
node scripts/compare-models.mjs --models gpt-5.6-luna --effort low --cases 1
node scripts/compare-models.mjs --help
```

脚本只使用内置构造对话，不读取用户聊天记录。每次生成使用独立临时线程；一组比较固定读取一次提示词。中文组直接读取完整角色文件，双语组直接调用当前 `server/providers.mjs` 的 `systemPrompt({config:{replyMode:'ja-zh'}})`。桥接九个本地协议测试通过，覆盖模型与 effort 转发、不支持选项、取消生成、工具隔离及登录流程；这与真实模型请求是两组不同验证。
